## 递归媒体播放器 v1.0.4

一个适用于 Windows 10/11 的图片与视频轮播工具。将windows设备变为电子相框，选择一个文件夹，就能把家庭照片、店铺商品图、展览作品或活动记录展示在电视、电脑和大屏幕上。

### 下载与启动

下载 `RecursiveMediaPlayer-win-x64-v1.0.4.zip`，完整解压后双击 `RecursiveMediaPlayer.exe`。此自包含版本已包含 .NET 运行时，无需另外安装 .NET。请保留解压目录内的全部文件。

### 功能

- 递归扫描 PNG、JPG、JPEG 图片和 MP4 视频，并混合播放。
- 图片与视频分别筛选横屏、竖屏、所有或禁用。
- 支持自然路径顺序、随机不重复轮次和循环播放。
- 支持全屏和窗口化；点击画面或按 `Esc` 返回设置，按空格暂停或继续。
- 配置窗口提供离线教程和“清空配置和缓存”功能。清空会重置软件设置和索引，不会删除图片或视频。

视频兼容性取决于 Windows 媒体组件和视频编码。完整说明见仓库 README 和 `src/使用教程.md`。

压缩包校验值见同目录 `.zip.sha256` 文件。

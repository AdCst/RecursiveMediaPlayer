# 递归媒体播放器使用教程

这个软件可以把一个文件夹里的图片和视频接着播放，适合看相册、展示素材或在屏幕上循环展示内容。第一次使用，按下面的步骤操作即可。

## 一、第一次开始播放

1. 打开软件，找到“文件夹”右边的“浏览”按钮。
2. 点击“浏览”，选择放有图片或视频的文件夹，再确认选择。选文件夹即可，不需要逐个选文件。
3. “图片时长”先保留为 3000，表示每张图片播放 3 秒。
4. “图片筛选”和“视频筛选”都选“所有”，这样不容易漏掉想看的内容。
5. 第一次建议选“窗口化”，方便熟悉操作；其他选项可以保持默认。
6. 点击蓝色的“开始播放”大按钮（高度已增至原来的三倍）。

第一次使用某个文件夹时，需要等待扫描完成。文件多或磁盘慢时，等待时间会更长。以后使用相同的文件夹，软件会优先读取缓存，并在后台检查新增和修改的文件。

## 二、播放时怎么操作

- 暂停或继续：按键盘上的空格键。暂停时画面停住，不会出现暂停按钮。
- 返回设置：用鼠标点击播放画面，或者按 Esc 键（通常在键盘左上角）。
- 关闭播放窗口：返回设置页面，软件仍然开着。
- 完全退出软件：先返回设置页面，再点“退出”，或关闭设置窗口。
- 手动同步文件夹变化：点击“清空配置和缓存”，确认后重新选择文件夹并点击“开始播放”。软件会清除旧扫描记录并重新扫描。

播放画面里没有按钮、进度条和文件名，这是正常设计。鼠标不动约 2 秒后，指针会隐藏；移动鼠标就会重新出现。

## 三、每个设置是什么意思

### 文件夹与“包含子文件夹”

“文件夹”是软件查找内容的起点。例如，你选择“照片”，并勾选“包含子文件夹”，软件也会查找“照片”里面的“旅行”“家人”等文件夹。

取消勾选后，只播放所选文件夹最外面一层的内容，不查找里面的文件夹。

支持 PNG、JPG、JPEG 图片和 MP4 视频。其他格式不会加入播放列表。不要只修改文件后缀名来转换格式，那样不会真正改变文件格式。

### 图片时长

填写整数，单位是毫秒（ms）。1000 毫秒等于 1 秒。

- 1000：每张图片显示 1 秒。
- 3000：每张图片显示 3 秒。
- 10000：每张图片显示 10 秒。

允许填写 100 到 3600000。不要在输入框里写“3秒”或“3000ms”，只填数字即可。视频会播放到结束，不受图片时长影响。

### 图片筛选与视频筛选

- 所有：横屏、竖屏都播放。不确定时选这个。
- 横屏：只播放宽度大于或等于高度的内容。
- 竖屏：只播放高度大于或等于宽度的内容。
- 禁用：不播放这一类内容。图片选“禁用”就只看视频；视频选“禁用”就只看图片。

两项都选“禁用”时，没有可播放内容，会提示“未找到可播放文件”。返回设置后，把至少一项改为“所有”、横屏或竖屏即可。

两行设置互不影响。例如，图片可以只看横屏，视频可以选“所有”。正方形内容在横屏和竖屏筛选下都会保留。

图片和视频都会保持自身比例。屏幕边上有黑边是正常的，软件不会为了铺满屏幕而把画面拉宽或压扁。

### 播放顺序

- 顺序：按文件夹和文件名自然排序，例如“照片2”排在“照片10”前面。
- 随机：打乱顺序，一轮内每个文件只播放一次。开启循环后，每一轮会重新打乱。

### 全屏与窗口化

- 全屏：画面占满屏幕，没有标题栏。按 Esc 或点击画面就能返回设置。
- 窗口化：像普通窗口一样显示，可以拖动标题栏、调整大小、最小化和最大化。下次会记住普通窗口的尺寸。

### 循环播放与静音

- 勾选“循环播放”：播完一轮后继续播放。取消后，播完显示“播放结束”，点击画面返回。
- 勾选“静音”：视频不出声音。不勾选时，会播放视频原有的声音。

### 清空配置和缓存

如果新增、修改或删除了媒体文件，而播放列表没有及时更新，可以点击设置窗口里的“清空配置和缓存”，并在确认提示中选择“是”。软件会删除 `%LOCALAPPDATA%\RecursiveMediaPlayer` 里的设置和扫描缓存，然后恢复默认选项。

清空不会删除图片、视频或所选文件夹。清空后请重新选择媒体文件夹，再点击“开始播放”；软件会重新扫描当前文件夹里的实际内容。文件较多时，重新扫描需要一些时间。若不想清空，也可以返回设置页面再次点击“开始播放”触发扫描。

## 四、下次打开为什么直接播放了

点击“开始播放”时，软件会保存设置。下次打开，如果上次选择的文件夹还存在，就会按上次设置直接播放。

要更换文件夹或调整设置，点击播放画面或按 Esc 返回设置页面即可。需要再看这份教程时，点击设置页面右上角的“i”按钮。教程可以离线阅读，点“关闭教程”或按 Esc 返回设置。

## 五、常见问题

### 提示“未找到可播放文件”

先点击画面返回设置，然后检查下面几项：

- 是否选对了文件夹？里面有没有 PNG、JPG、JPEG 或 MP4 文件？
- 文件是否都放在更深一层的文件夹里？如果是，请勾选“包含子文件夹”。
- 是否选了过于严格的比例？先把图片和视频都改成“所有”再试。
- 文件是否损坏或无法打开？无法识别尺寸或无法播放的文件会被跳过。

### 某个视频不播放，或者没有声音

MP4 文件可能使用不同的视频编码，能否播放与 Windows 的媒体组件有关。部分编码可能不受当前系统支持，软件会跳过无法播放的文件。

没有声音时，先检查“静音”是否勾选，再检查系统音量、扬声器或耳机，以及视频本身是否带声音。

### 刚加入的文件没有马上出现

使用缓存启动后，软件会在后台检查变化。开启循环时，新列表会在当前一轮结束后使用。想尽快更新，可以返回设置，重新点击“开始播放”；首次后台检查尚未完成时，仍可能需要等待。

### 想换素材或退出，但找不到按钮

直接点击播放画面，或按 Esc，即可返回设置页面。要彻底退出，请在设置页面点击“退出”。

### 文件有变化，但播放列表还没更新

返回设置页面，点击“清空配置和缓存”，确认后重新选择素材文件夹并开始播放。图片和视频文件不会被删除，只会重建软件的索引和配置。
